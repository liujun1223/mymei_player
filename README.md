# MYMEI Player

艾美影库（MYMEI）播放器的 Home Assistant 自定义集成，支持 RS-232 串口与 IP（TCP）两种控制通道。

协议依据：《MYMEI 串口协议 V7.0》《MYMEI IP 控制协议 V7.0》。

## 控制通道

| 通道 | 参数 | 说明 |
| --- | --- | --- |
| TCP | 33080 长连接（HEX 帧） | 连接后设备主动推送视频/音乐播放事件，无需轮询 |
| RS-232 | 9600 8N1，帧 `7F 57 53 02 <命令码> <参数> <校验和> 0D` | 回执 `… 02 <命令码> 01 03 0D` 表示成功 |

双通道可只配其一或同时配置：优先走 TCP，断线/不可达自动降级串口，60 秒后自动重试 TCP。

> 协议 V7.0 没有状态查询命令，电源与播放状态由命令回执和事件推送维护，HA 侧会按命令语义做乐观更新。

## 功能

- **开关机**：待机开/待机关（关屏幕）/待机切换/重启
- 播放/暂停/停止、音量/静音（协议无上一曲/下一曲，未提供对应按钮）
- 状态实时同步：电源状态、播放状态、媒体类型（TCP 事件推送）
- `select` 遥控命令选择器：方向/确定/数字键/菜单/音轨/字幕/分辨率/音频输出等 60+ 指令
- TCP 断线自动重连，设备待机走串口，开机后自动恢复

## 安装

### HACS

1. HACS → 集成 → 右上角菜单 → 自定义存储库
2. 添加 `https://github.com/liujun1223/mymei_player`，类别选择「集成」
3. 搜索 “MYMEI Player” 安装，重启 Home Assistant

### 手动安装

把 `custom_components/mymei_player` 复制到 Home Assistant 的 `config/custom_components/` 目录，重启。

## 配置

添加集成后二选一：

- **自动识别串口**：扫描本机串口，识别到设备后可选填 IP
- **手动配置**：串口 / IP 至少填一项
